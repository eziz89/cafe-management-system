# Cafe Management System

A modern Laravel-based cafe management system featuring online ordering, reservations, cart functionality, and an admin dashboard.

---

## Features

- User authentication
- Category-based menu browsing
- Dish management system
- Shopping cart functionality
- Online ordering system
- Reservation system
- Admin dashboard
- Order management
- Responsive modern UI

---

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade Templates
- Tailwind CSS
- JavaScript
- Vite
